## 数据来源人工确认规则（全局前置条件）

本模块为独立模块，凡使用网点、目的流向、产品类型、货物类型、公斤段等外部系统主数据，均须由业务负责人和对应来源系统负责人在开发联调前人工确认字段映射。每项映射至少记录：**本模块字段、来源系统及模块、来源字段名称/编码、业务含义与匹配口径、数据类型/单位/枚举转换、更新时间或取数时点、确认人、确认日期**。

未完成确认的字段统一标记为“待确认数据来源”，不得根据页面同名字段、原型示例或经验自行认定映射关系，也不得作为查询、匹配、接口联调或验收的最终口径。一个目标字段由多个来源字段计算时，须同时确认转换规则和空值、异常值处理方式；来源字段或口径变更后须重新人工确认。本规则只约束数据对接与验收，不要求页面展示数据来源信息。

## 1. 模块目标

政策配置列表用于查询已维护的网点返利政策，帮助业务人员按生效日期、网点、目的流向及政策维度定位配置，并核对政策覆盖范围。

本期建立查询、列表、适用范围编辑与拆分、启用状态编辑、批量停用及删除的业务口径；Excel 导入及失败信息池由独立文档定义。

## 2. 功能范围

| 功能 | 本期说明 |
| :--- | :--- |
| 查询政策 | 按生效日期、寄件网点、目的流向、货物类型、公斤段、考核周期、是否启用组合查询 |
| 查看列表 | 展示政策的生效日期及适用范围字段 |
| 分页查看 | 默认每页20条，支持切换每页条数和翻页 |
| 选择政策 | 支持逐条勾选；表头全选作用于当前筛选结果的全部记录，不受分页影响 |
| 批量停用 | 对已选择政策执行批量停用，不提供批量启用 |
| 删除政策 | 未生效政策支持单条或批量删除；已生效政策只能停用 |
| 编辑适用范围 | 产品类型、货物类型、公斤段支持全选、单选和多选 |
| 拆分与校验 | 提交时按自然月和三个适用范围维度拆成原子政策，并在保存前完成必填、枚举、内部重复和启用政策冲突校验 |

**不在本期范围：**

- 页面不提供“复制上月”功能；
- Excel导入、导入任务和失败信息池由《政策导入业务PRD》定义；
- 政策详情、每日配置日历；
- 政策审批和版本状态机；

### 2.1 角色与数据范围

## 4. 核心业务规则

| 规则ID | 规则 | 确认日期 |
| :--- | :--- | :--- |
| R01 | **空条件查询**：全部查询字段未选择时，不附加业务过滤条件，返回当前页面可查询的全部政策。 | 2026-09-19 |
| R02 | **日期区间重合**：政策生效开始日期 ≤ 查询结束日期，且政策生效结束日期 ≥ 查询开始日期时，视为日期命中；任意一天重合即展示。 | 2026-09-19 |
| R03 | **同字段多选**：同一查询字段选择多个值时采用“或”关系，命中其中任意一个值即可。 | 2026-09-19 |
| R04 | **跨字段组合**：不同查询字段之间采用“且”关系，记录必须同时满足全部已填写条件。 | 2026-09-19 |
| R05 | **网点与流向组合**：寄件网点和目的流向同时多选时，返回所选网点与所选目的流向之间实际存在的政策组合，不生成系统中不存在的组合。 | 2026-09-19 |
| R06 | **拆分后字段命中**：每条政策只保存一个产品类型、一个货物类型和一个公斤段；查询所选值包含该条政策对应值时视为命中。 | 2026-09-20 |
| R07 | **考核周期**：考核周期只包含周、月；选择一个或两个周期时，按R03处理。 | 2026-09-19 |
| R08 | **查询重置页码**：执行查询、重置或切换每页条数后，列表从第一页开始展示。 | 2026-09-19 |
| R09 | **分页统计口径**：总记录数为当前全部查询条件过滤后的记录数，不是当前页记录数。 | 2026-09-19 |
| R10 | **全结果全选**：列表表头全选勾选当前筛选结果的全部政策，不受分页影响；取消全选时取消当前筛选结果内的全部选择。 | 2026-09-20 |
| R15 | **启用重复校验**：编辑时将停用政策改为启用，必须检查是否存在业务维度相同且生效日期重叠的启用政策；存在时阻止保存并提示冲突政策。 | 2026-09-19 |
| R16 | **批量停用**：支持将选中的一条或多条启用政策批量改为停用；已停用政策保持不变，不提供批量启用。 | 2026-09-19 |
| R17 | **重新启用入口**：需要启用新政策时通过政策导入完成；批量操作区不提供启用入口。 | 2026-09-19 |
| R18 | **导入排列组合**：Excel 中产品类型、货物类型、公斤段的逗号多选值必须拆分，并按三类取值的笛卡尔积逐条生成政策；列表不得将多个值合并在同一条政策中。 | 2026-09-20 |
| R19 | **导入后展示**：导入成功后返回政策配置列表、清空原查询条件并回到第一页，使本次生成的政策可直接查看。 | 2026-09-20 |
| R20 | **删除限制**：尚未生效的政策可以删除；已生效或已经参与返利计算的政策不得物理删除，只能停用，并保留原始配置、历史版本和历史计算记录。 | 2026-09-20 |
| R21 | **批量删除**：批量删除只删除所选尚未生效政策；同时选中已生效政策时予以保留，并在确认及结果反馈中展示保留数量。 | 2026-09-20 |
| R22 | **启用状态查询**：是否启用固定为全部、启用、停用；默认全部，选择启用或停用时只返回对应状态，重置后恢复全部。 | 2026-09-20 |
| R23 | **编辑页多选**：编辑返利配置时，产品类型、货物类型、公斤段均支持全部、单选和多选，三个字段均为必填。 | 2026-09-23 |
| R24 | **编辑提交拆分**：提交时先按生效日期覆盖的自然月拆分，再按产品类型×货物类型×公斤段的笛卡尔积拆分；生成数量=自然月数×产品类型数×货物类型数×公斤段数。 | 2026-09-23 |
| R25 | **原子政策保存**：拆分后的每条政策只保存一个产品类型、一个货物类型和一个公斤段，列表逐条展示，不保存逗号合并值。 | 2026-09-23 |
| R26 | **提交前校验**：保存前校验日期、必填项、枚举值、拆分结果内部重复，以及每条待生成原子政策与现有启用政策的效期冲突。 | 2026-09-23 |
| R27 | **整次提交原子性**：任一拆分结果校验失败时阻止整次提交，提示发生冲突的产品类型、货物类型和公斤段；不得只保存部分组合，原政策保持不变。 | 2026-09-23 |
| R28 | **编辑替换**：全部校验通过后，用本次生成的全部原子政策替换被编辑的原政策；跨月时每个自然月分别生成对应效期的原子政策。 | 2026-09-23 |
| R29 | **返利单价精度**：日、工作日、周日、节假日返利单价最多输入两位小数；超出时阻止保存并提示，页面所有返利单价统一显示两位小数。 | 2026-09-23 |

## 5. 数据与性能规则

| 规则ID | 规则 |
| :--- | :--- |
| R11 | 页面只加载当前页所需数据，不一次性加载全部政策。 |
| R12 | 每次查询必须同时返回当前页记录和符合条件的总记录数。 |
| R13 | 默认每页20条；允许切换为10条、20条、50条或100条。 |
| R14 | 页码超过可展示数量时允许折叠中间页码，但不得影响跳页结果。 |

默认排序固定为：生效结束日期倒序；生效结束日期相同时，按生效开始日期倒序。

## 6. 边界与异常处理

| 场景 | 系统处理 |
| :--- | :--- |
| 查询开始日期晚于结束日期 | 不执行查询，提示“生效日期开始时间不能晚于结束时间” |
| 查询条件无匹配结果 | 返回0条记录，不回退为全量数据 |
| 当前页记录因数据变化减少 | 自动修正到仍存在的最后一页；无数据时展示第0/0页 |
| 主数据名称发生变化 | 列表展示当前主数据名称；历史政策是否保留名称快照不在本期定义 |
| 查询服务失败 | 保留用户已填写的查询条件，提示查询失败，允许重新查询 |
| 数据量较大 | 服务端按查询条件分页返回，不允许一次返回几十万条政策记录 |

## 8. 开发适配边界

| 边界项 | 要求 |
|---|---|
| 开发依据 | 研发人员或编码智能体必须实现本 PRD 已确认的业务规则、页面结果和验收标准 |
| 工程适配 | 开发前先读取现有工程，沿用项目已有的架构、接口规范、组件体系、权限和异常处理机制 |
| 数据规模 | 必须满足几十万条政策数据的查询和分页使用要求；具体前后端、存储与性能方案由技术设计确定 |
| 文档边界 | 本 PRD 不规定接口路径与方法、请求响应结构、错误码、数据库表与索引、技术栈、组件名称、状态变量或代码目录 |
| 缺口处理 | 现有工程能力不足或实现口径仍不明确时，先形成技术设计或待确认问题，不在产品 PRD 中补成技术事实 |
| 范围控制 | 编辑实现本文确认的适用范围多选、拆分校验和启用状态行为；删除仅实现本文确认的未生效政策删除规则；不得自行增加“复制上月”入口或复制流程 |
