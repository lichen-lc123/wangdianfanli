## 数据来源人工确认规则（全局前置条件）

本模块为独立模块。页面中由外部系统提供的数据，须在开发联调前由业务负责人和对应来源系统负责人人工确认“本模块字段—来源系统及模块—来源字段名称/编码—业务口径”的映射，并补充数据类型、单位、枚举转换、更新时间、确认人和确认日期。未确认项标记为“待确认数据来源”，不得依据同名字段或原型示例自行匹配，也不得作为联调和验收的最终口径。

该规则不要求在用户页面展示来源字段，也不改变本文定义的页面字段和交互；来源映射变化时须重新确认，并同步评估页面展示、筛选、详情和历史结果的影响。

## 1. 页面目标与骨架

返利管理中所有返利单价（包括列表、详情、周期汇总和变化记录）统一显示两位小数；该页面为结果展示和操作页面，不提供返利单价编辑入口。金额精度按业务规则另行处理。

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 返利管理 |
| 页面入口 | 网点返利 → 返利管理 |
| 一级页签 | 日返利、周期返利；默认日返利 |
| 页面骨架 | 固定页签＋搜索卡片＋结果卡片＋固定分页；两个页签均不展示顶部统计卡片 |
| 设计规范 | `RH_design_token_v3.0`；暖橙色、白色卡片、灰色边框 |

切换页签只改变查看范围，分别保留各自的筛选条件、分页位置和列表选中状态，不改变政策、计算或资金结果。

## 2. 固定与滚动

1. 左侧菜单、顶部导航、页签和搜索区固定，不随表格滚动。
2. 表格占据剩余空间，在结果卡片内部上下和左右滚动。
3. 分页固定在结果卡片底部。
4. 日返利勾选列固定在最左侧，操作列固定在最右侧。
5. 周期返利页签首列名称为“返利周期”，固定在最左侧；该字段值仍取命中政策的生效开始日期至生效结束日期，来源和筛选、统计逻辑不变。操作列固定在最右侧。
6. 固定列与滚动区使用轻微层级区分；操作列不增加竖向分隔线。

## 3. 日返利页签

### 3.1 顶部结构

日返利页签不展示顶部统计卡片。进入日返利后，在页签下方直接展示搜索卡片和结果列表，待发放数量、返利金额等信息通过列表字段、状态及结果总数查看。

### 3.2 搜索区

桌面端一行四格，字段名称与控件左右排列。字段顺序：返利统计日期、寄件网点、目的流向、产品类型、货物类型、公斤段、是否有返利、考核周期、状态、查询/重置。

| 字段 | 控件与交互 |
| :--- | :--- |
| 返利统计日期 | 单日历日期区间控件；同一面板先选开始再选结束；点击外部关闭 |
| 寄件网点 | 可搜索多选；控件显示“输入或选择网点”，展开后搜索框自动聚焦；输入任意网点名称片段即时过滤候选项，支持全选和删除已选标签 |
| 目的流向 | 可搜索多选，按名称包含式模糊搜索，支持全选 |
| 产品类型、货物类型、公斤段 | 不搜索的多选框，支持全选 |
| 是否有返利、考核周期、状态 | 单选下拉，默认全部 |

多选值以可删除标签展示；标签换行时控件在限定范围内增高，超过后内部上下滚动。不同条件之间按“且”匹配，同一多选条件内按“或”匹配。

货物类型候选项及所有列表、详情统一展示轻泡、重泡、重货，不再展示轻抛、重抛。

### 3.3 日返利列表

字段顺序严格引用字段清单：选择、返利统计日期、寄件网点、目的流向、产品类型、货物类型、公斤段、日基准量、结算总重、差值、返利单价、返利、考核周期、状态、发放时间、最新更新时间、操作。

展示规则：

- 重量、单价和金额单位写在表头，单元格只显示数字和必要正负号；
- 所有业务数值保留两位小数并居中；
- 差值为正使用橙色，负数和0使用灰色，同时保留正负号；
- 已发放使用暖灰色状态，不使用绿色；待发放使用橙色；
- 发放时间、最新更新时间精确到秒；
- 列间距紧凑，优先使考核周期进入常用桌面宽度可视区域。

### 3.4 行操作

操作顺序固定为：发放操作、详情、周期返利。全部为纯文字操作，使用规范次要橙色，间隔16px，无底色、边框、圆角、阴影和竖线。

| 条件 | 第一个操作 |
| :--- | :--- |
| 待发放、金额>0、T+1日16:00后已完成计算 | 发起返利；点击后进入人工审核确认 |
| 待发放、金额=0 | 无需返利，禁用 |
| 已发放 | 已发放，禁用 |

### 3.5 单条、批量与全部返利

1. 列表工具栏与政策导入保持一致，所有列表级操作按钮集中排列在工具栏左侧；“批量发起返利”在前，“全部返利”在后，两项操作均须经过人工审核确认后发放。
2. 已选数量、结果总数和实时更新说明排列在工具栏右侧，不与操作按钮混排。
3. 已发放或返利为0的记录选择框不可用。
4. 表头全选作用于当前筛选结果全部可发放记录，不受分页限制。
5. 切换筛选条件后，隐藏记录取消选择。
6. 工具栏实时展示已选数量；无选择时批量返利不可用。
7. 同时保留单条、批量和全部返利。
8. 返利统计日期T对应T日09:00至T+1日09:00；系统在T+1日16:00后计算日返利。确认弹框用于人工审核，展示记录数和返利总金额，确认按钮文案为“审核通过并发放”。

## 4. 返利详情

点击“详情”打开右侧抽屉，桌面端宽度约为页面2/3，窄屏全屏。顶部展示总重量、基准重量、返利单价、差值、首次发放金额、当前应返金额、累计调整金额和最后变化时间。

### 4.1 当前运单

- 字段引用字段清单；运单按发货时间倒序；
- 所有运单的网点、流向、产品、货物类型和公斤段必须与所点日返利记录一致；
- 当前运单只展示已纳入始发有效扫描货量的运单；始发分拨在同一统计窗口内存在到件、装车或卸车任一扫描即可，装车、卸车可替代到件；800kg以上融速达、同分拨寄件及三种有效扫描均缺失的运单不得出现在当前参与计算的运单列表中；
- 明细分页，不一次性渲染全部运单；
- 正式开发不提供修改或删除运单操作。HTML原型中的测试按钮必须忽略。
- HTML原型点击“修改”后，当前行切换为编辑状态，可修改寄件网点、目的流向、产品类型、货物类型、公斤段和结算重量；提供“保存”“取消”。点击“删除”或保存修改后，须生成唯一的原型变更编号，并立即刷新返利变化、运单变化和详情顶部的总重量、差值、当前应返金额、累计调整金额、最后变化时间。
- 只修改结算重量且业务维度不变时，运单继续留在当前列表，当前统计范围按重量差额重算。
- 任一业务维度变化时，保存后运单从当前运单列表移除；原统计范围扣除变更前重量，修改后的统计范围增加变更后重量。新统计范围已存在时更新对应日返利结果，不存在时在原型中新增一条测试日返利结果。

### 4.2 返利变化

只展示：变更时间、变更前重量、变更后重量、重量差额、变更前返利单价、变更后返利单价、变更前金额、变更后金额、差额。

重量差额以可点击文字展示；点击后切换到“运单变化”，定位并突出对应变化记录。金额差额只展示。

每次运单变化新增一条记录，按变化发生时间倒序展示。变更前后重量为当前返利组合的汇总重量，变更前后金额按对应汇总重量、基准量和返利单价重新计算。原型测试修改、删除生成的记录须带有与运单变化一致的变更编号。

### 4.3 运单变化

直接点击页签时展示全部运单变化。字段顺序引用字段清单。由返利变化跳转时，只定位高亮目标记录，不隐藏其他记录。

每次运单变化必须展示对应运单号、变更时间、变更类型、变更前后归属、变更前后结算重量、重量差额和返利调整，并通过变更编号与返利变化一一关联。修改结算重量时记录修改前后重量；删除时变更后重量记为0，变更后归属显示“已移出当前计算”。

没有发生任何变化时展示明确空状态。未发放记录发生变化后也展示计算变化，但不展示为账户资金调整；已发放记录同时体现相应补发或扣回结果。

### 4.4 原型测试边界

“当前运单”的修改、删除按钮及其即时联动仅用于验证上述追溯交互。原型中目标统计范围优先使用该范围已有政策参数；没有对应结果时使用测试数据生成演示结果，不代表正式政策匹配口径。正式开发的数据变化必须来自人工确认后的外部运单数据源，并由系统重新匹配目标范围的有效政策，不得在返利管理页面直接修改或删除运单；原型按钮、编辑控件及前端临时数据不得进入正式开发范围。

## 5. 周期返利日历

日返利操作“周期返利”和周期返利列表操作“详情”打开同一个周期详情页面。页面顶部提供“周期概览”“返利变化”两个 Tab，默认进入“周期概览”；切换 Tab 不关闭抽屉，也不改变当前周期和业务维度。

### 5.1 周周期

- 按1—7日、8—14日、15—21日、22—28日、29日—月末分段；
- 每段左侧横向展示每天的日期卡片，右侧为该周统计栏；
- 周期结束后展示本周是否达标、本周总返利和重量差额；
- 周期最后一个返利统计日的数据窗口结束当天17:00自动计算整个周期扣款，例如1—7日周期在8日17:00执行；
- 周期未结束时只展示“周期未结束”和结束日期。

### 5.2 月周期

- 使用周一至周日自然月日历；当月1日按实际星期位置起始；
- 最右侧为贯穿日历高度的月度统计栏；
- 月结束后展示本月是否达标、本月总返利、结算总重、累计基准量和重量差额；
- 未结束时只展示“周期未结束”和结束日期。

日期卡片展示日期、超基准/差基准/待统计、实际重量、基准重量、重量差和当日返利。状态必须有文字，不能只用颜色。

### 5.3 返利变化

“返利变化”按变更时间倒序展示：变更时间、变更原因、变更前周期结算总重、变更后周期结算总重、重量差额、变更前总返利、变更后总返利、返利差额、处理状态。数值保留两位小数，重量和金额单位写在表头，差额保留正负号。

变化记录由运单改单、统计范围变更、政策历史重算或周期自动处理触发；只追加新记录，不覆盖历史记录。两个入口打开的返利变化须基于同一周期结果和业务维度，内容保持一致。

## 6. 周期返利页签

### 6.1 顶部结构

周期返利页签不展示周期结果数、未达标周期数、应回扣金额、已回扣金额和待回扣金额等顶部统计卡片。进入周期返利后，在页签下方直接展示搜索卡片和结果列表。

### 6.2 搜索区

搜索字段按顺序为：返利周期（时间段）、寄件网点、目的流向、产品类型、货物类型、公斤段、考核周期、是否有返利，并提供查询和重置。所有搜索控件的选择方式和输入搜索能力沿用日返利：返利周期使用单个日期范围日历；寄件网点、目的流向支持文字搜索和多选；产品类型、货物类型、公斤段支持多选但不提供文字搜索；考核周期、是否有返利为单选。多选项以可删除标签显示，点击控件外部关闭下拉；是否有返利按总返利判断，大于0为“是”、等于0为“否”。字段来源与枚举引用字段清单。

### 6.3 列表

字段顺序：返利周期、寄件网点、目的流向、产品类型、货物类型、公斤段、考核周期、总返利、周期基准量、周期结算总重、差值、周期最高返利单价、初始返利、总扣罚、操作。返利周期仅为本页显示名称；其值、数据来源和业务口径与原生效日期字段一致。

- 数值字段居中并保留两位小数；单位写在表头；
- 返利周期左固定，操作右固定，中间字段横向滚动；
- 操作仅提供“详情”，不提供返利或回扣按钮；
- 周期计算、回扣、补扣和退回由系统自动执行的说明始终可见。

### 6.4 周期详情

点击“详情”进入第5章定义的统一周期详情页面，默认展示周期概览，可切换至返利变化。周期概览继续展示日历、累计实际重量、累计基准重量、差额、周期最高返利单价、周期内日返利总额、应回扣、已回扣、待回扣及自动处理结果。

周期未结束时不显示达标结论、总扣罚和总返利，只显示周期未结束和结束日期。

## 7. 分页

1. 日返利和周期返利默认每页20条，可选10、20、50、100条。
2. 页码只展示首页、当前页及相邻页、末页，不连续位置显示省略号。
3. 提供上一页、下一页、第N/M页和页码输入跳转。
4. 跳转值必须是1至总页数的整数；错误时不跳转并提示有效范围。
5. 查询、重置或切换每页条数后返回第一页。

## 8. 页面状态

| 状态 | 展示规则 |
| :--- | :--- |
| 初始 | 默认进入日返利，展示默认日期范围和第一页 |
| 加载 | 保留筛选条件和结构，显示加载状态，避免重复操作 |
| 空数据 | 当前页签结果卡片展示无匹配结果，不切换页签 |
| 查询失败 | 保留筛选条件，提示失败并允许重试 |
| 发放成功 | 状态改为已发放，写入发放时间与最新更新时间 |
| 发放失败 | 保持待发放，展示失败原因，不重复入账 |
| 周期未结束 | 不展示达标和扣罚结果 |
| 详情无变化 | 未发生任何运单或返利变化时展示暂无变化的空状态说明 |
