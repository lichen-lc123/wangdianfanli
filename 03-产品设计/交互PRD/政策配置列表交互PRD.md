## 数据来源人工确认规则（全局前置条件）

本模块为独立模块。页面中引用的外部系统主数据，须在开发联调前由业务负责人和对应来源系统负责人人工确认“本模块字段—来源系统及模块—来源字段名称/编码—业务口径”的映射，并补充数据类型、单位、枚举转换、更新时间、确认人和确认日期。未确认项标记为“待确认数据来源”，不得依据同名字段或原型数据自行匹配，也不得作为查询、联调和验收的最终口径。

该规则不要求在用户页面展示来源字段，也不改变本文定义的页面字段和交互；来源映射变化时须重新确认，并同步评估筛选、列表展示和历史政策的影响。

## 1. 页面目标与范围

| 项目 | 内容 |
| :--- | :--- |
| 页面名称 | 政策配置 |
| 页面目标 | 按效期和政策适用维度查询返利政策，并在列表中核对政策覆盖范围 |
| 页面入口 | 网点返利 → 政策导入 → 政策配置页签 |
| 骨架结构 | 搜索卡片 + 列表卡片 |
| 默认数据 | 查询字段均为空，列表展示全部政策的第一页 |
| 默认排序 | 生效结束日期倒序；结束日期相同时按生效开始日期倒序 |

---

### 1.1 角色权限与页面呈现

- 政策配置页面仅对具备相应权限的总部返利管理员开放；网点查看人员不展示政策配置入口。
- 总部返利管理员可按授权查看和维护全部网点政策；网点查看人员仅在返利管理中查看本人所属网点数据。
- 无权访问页面或操作时不展示对应入口；通过直接链接访问时显示无权限提示。新增、编辑、启停、删除及政策数据读取均须按授权范围校验。
- 具体角色绑定沿用现有工程权限体系。
## 2. 页面骨架

页面主体从上到下为：页签 → 搜索卡片 → 12px卡片间距 → 列表卡片。

| 区域 | 内容 |
| :--- | :--- |
| 搜索卡片 | 查询字段、查询按钮、重置按钮 |
| 列表卡片 | 工具条占位、查询结果数量、政策表格、分页 |

列表工具栏依次提供新增配置、Excel导入、批量停用、批量删除；不展示“复制上月”，也不提供对应复制流程。

搜索卡片与列表卡片分别使用白色背景、圆角和边框，不合并为同一卡片。

### 2.1 固定与滚动规则

| 区域 | 交互规则 |
| :--- | :--- |
| 左侧菜单 | 固定在页面左侧，不随列表滚动，不出现独立滚动条 |
| 顶部栏与页签 | 固定在页面框架内，不随列表数据滚动 |
| 搜索区 | 固定在内容区顶部，不随列表滚动；下拉选择和日期面板可以覆盖列表区域 |
| 列表工具条 | 位于搜索区下方，保持在列表滚动区域之外 |
| 列表 | 占用搜索区、工具条和分页之外的剩余屏幕空间；在区域内部支持上下及左右滚动，表头保持可见 |
| 分页栏 | 固定在内容区最下方，不随列表滚动 |
| 页面滚动 | 桌面端页面主体不产生整体滚动，滚动只发生在列表区域；窄屏允许页面自然滚动 |

## 3. 搜索区

### 3.1 布局

- 桌面端使用四列栅格，每个字段名称与控件左右排列；
- 第一行：生效日期、寄件网点、目的流向、货物类型；
- 第二行：公斤段、考核周期、是否启用、查询操作组；
- 查询、重置固定在第二行最右侧；
- 中等宽度改为两列，窄屏改为一列；
- 默认控件高度32px。

### 3.2 查询字段

| 顺序 | 查询字段 | 控件类型 | 默认状态 | 交互规格 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | 生效日期开始、生效日期结束 | 单日历日期区间选择器 | 空，显示“请选择时间段” | 页面只显示一个输入框；点击后打开一个日历，在同一日历内依次选择开始日期和结束日期 |
| 2 | 寄件网点 | 可搜索多选框 | 空，显示“请选择网点” | 支持按网点名称包含式模糊搜索和多选，不搜索网点编码 |
| 3 | 目的流向 | 可搜索多选框 | 空，显示“请选择流向” | 支持按目的流向名称包含式模糊搜索和多选，不搜索目的流向编码 |
| 4 | 货物类型 | 多选框 | 空，显示“请选择类型” | 不提供文字搜索，直接勾选 |
| 5 | 公斤段 | 多选框 | 空，显示“请选择公斤段” | 不提供文字搜索，直接勾选 |
| 6 | 考核周期 | 多选框 | 空，显示“请选择周期” | 不提供文字搜索，直接勾选周、月，可同时选择 |
| 7 | 是否启用 | 单选下拉框 | 全部 | 固定选项为全部、启用、停用；选择启用或停用后仅展示对应状态 |

### 3.3 生效日期交互

| 交互 | 规则 |
| :--- | :--- |
| 打开 | 点击时间段输入框，展开单月日历；默认定位当前月，已有值时定位开始日期所在月份 |
| 选择开始日期 | 第一次点击日期后标记为开始日期，并提示继续选择结束日期 |
| 选择结束日期 | 第二次点击开始日期当天或之后的日期，形成闭区间，并高亮区间内日期 |
| 点击更早日期 | 第二次点击早于开始日期时，将该日期重新作为开始日期，等待选择结束日期 |
| 跨月 | 使用上月、下月按钮切换月份，已选开始日期保持 |
| 确认 | 开始日期和结束日期均已选择时可点击“确认日期” |
| 清除 | 清空已选日期并关闭日历，输入框恢复“请选择时间段” |
| 点击外部 | 关闭日历；未确认的临时选择不写入查询条件 |

### 3.4 多选交互

| 交互 | 规则 |
| :--- | :--- |
| 默认状态 | 无选中值，不显示“全部”标签；业务含义为不限制该字段 |
| 勾选 | 支持单选、多选和全选 |
| 选中展示 | 每个已选值以独立标签显示在对应选择框内 |
| 删除标签 | 点击标签右侧“×”取消该值，其他已选值保留 |
| 高度 | 无选中值时保持32px；标签换行时自动增高，最大高度96px |
| 内容过多 | 达到最大高度后在选择框内部上下滚动查看标签 |
| 下拉关闭 | 点击选择框外区域关闭；点击另一个选择框时，前一个自动关闭 |
| 下拉内部 | 输入搜索词、滚动或勾选时保持展开 |
| 名称搜索 | 寄件网点和目的流向按名称包含关系过滤候选项；无结果时显示“没有匹配项” |

### 3.5 查询操作

| 操作 | 页面行为 |
| :--- | :--- |
| 查询 | 按当前已确认条件刷新列表并回到第一页；成功不展示Toast；关闭所有展开的选择框 |
| 重置 | 清空日期、搜索词和全部多选标签，关闭所有下拉，刷新全量列表并回到第一页 |
| 空条件查询 | 允许，展示全部政策的第一页 |

### 4.2 表格行为

| 行为 | 规格 |
| :--- | :--- |
| 表格宽度 | 内容超出卡片时横向滚动，不压缩多值字段到不可读 |
| 行勾选 | 支持；表头全选作用于当前筛选结果全部记录，不受分页影响 |
| 表头 | 固定在表格滚动区域顶部 |
| 行悬停 | 使用轻暖色背景提示当前行 |
| 排序 | 本期不提供表头排序图标 |
| 查询结果数量 | 工具条右侧展示“筛选结果，共 N 条配置” |
| 空结果 | 表格区域展示“没有与当前筛选条件匹配的政策” |
| 编辑启用状态 | 编辑页面提供是否启用开关；从停用改为启用并保存时检测重复政策，存在冲突则阻止保存、保持停用并提示冲突政策 |
| 批量停用入口 | 列表工具条提供“批量停用”；未选择政策时不可用，选中后显示已选数量；不提供“批量启用” |
| 批量停用确认 | 弹窗展示已选数量、将停用数量和已停用数量；点击“确认批量停用”后，只将所选启用政策改为停用 |
| 跨页选择 | 表头全选直接选择当前筛选结果全部记录；用户逐页手工勾选的记录也持续累计，批量按钮展示累计已选数量 |
| 选择清理 | 翻页保留已选记录；重新查询或重置查询条件时清空已选记录，避免停用当前结果外的政策 |
| 批量删除入口 | 列表工具条提供“批量删除”；未选择政策时不可用，选中后显示累计已选数量 |
| 批量删除确认 | 弹窗分别展示可删除的未生效政策数量和必须保留的已生效政策数量；确认后只删除未生效政策 |
| 删除限制提示 | 已生效政策不允许单条或批量删除，提示“该政策已经生效，不能删除，请使用停用” |
| 导入后定位 | 确认导入成功后切换到政策配置页签，清空查询条件并回到第一页；列表展示拆分生成的政策明细 |
| 拆分结果展示 | 产品类型、货物类型、公斤段均按单值逐行展示，不允许将逗号多选值原样显示在一个列表单元格中 |
| 查看配置 | 点击“查看”后，在对应政策行下方展开当月每日配置日历；日历每行14天，展示整月日期卡片及每天的有效基准重量、有效返利单价，周日和法定节假日使用特殊标记 |
| 查看行选中状态 | 日历展开期间，对应政策行使用暖橙底色和左侧橙色标识展示选中状态；关闭日历后取消选中状态，不改变复选框及批量选择结果 |
| 展开区精简 | 不展示“年月每日配置”标题、政策维度摘要、月份标题、周日/法定节假日图例和收起入口，仅保留日期卡片及“关闭”操作 |

### 4.3 编辑返利配置

| 交互 | 规格 |
| :--- | :--- |
| 适用范围多选 | 产品类型、货物类型、公斤段均使用多选控件，支持全选、单选和多选；三个字段均为必填 |
| 已选项展示 | 已选值在选择框内以标签展示；点击标签“×”仅移除对应值；点击控件外区域关闭下拉 |
| 原值回显 | 编辑一条原子政策时，三个多选控件分别回显该政策当前的单个产品类型、货物类型和公斤段 |
| 组合提示 | 页面实时展示产品类型数×货物类型数×公斤段数、自然月数及提交后预计生成的原子政策总数 |
| 返利单价输入 | 日、工作日、周日、节假日返利单价均最多输入两位小数；输入更多小数位时阻止保存并提示；已填单价和每日预览统一显示两位小数 |
| 提交拆分 | 提交后先按生效日期覆盖的自然月拆分，再按三个多选字段的笛卡尔积生成原子政策；列表中每条记录的三个字段均为单值 |
| 保存校验 | 提交前校验日期、三个多选必填、数值必填、拆分结果内部重复及与现有启用政策的重叠冲突 |
| 失败处理 | 任一组合失败时阻止整次保存，提示冲突组合；不生成部分记录，不改变原政策 |
| 成功处理 | 全部校验通过后用生成的原子政策替换原记录，关闭编辑页，刷新列表并提示生成条数 |

## 5. 分页

| 项目 | 规格 |
| :--- | :--- |
| 默认每页 | 20条 |
| 每页条数 | 10、20、50、100 |
| 左侧信息 | 总记录数 + 每页条数选择器 |
| 右侧控件 | 上一页、页码、下一页、当前页/总页数 |
| 大量页码 | 保留首页、尾页和当前页附近页码，中间使用省略号 |
| 无数据 | 展示“共0条”“第0/0页”，上一页和下一页不可用 |
| 条数切换 | 切换后返回第一页 |

## 6. 页面状态

| 状态 | 页面表现 |
| :--- | :--- |
| 初始状态 | 查询条件为空，列表展示全量数据第一页 |
| 加载中 | 表格区域展示骨架或加载状态，防止重复查询 |
| 查询成功 | 更新结果数量、表格和分页，不展示成功Toast |
| 查询为空 | 保留查询条件，展示空结果文案 |
| 查询失败 | 保留查询条件，表格区域展示失败状态和“重新查询”入口 |

## 7. Mock数据要求

- 列表至少30条，本期原型使用48条；
- 必须同时包含周、月两种考核周期；
- 至少覆盖3个寄件网点、16个目的流向；
- 产品类型、货物类型和公斤段包含多值示例；
- 至少一条记录只包含单个货物类型，用于验证多值展示差异；
- 数据只用于交互验证，不作为业务主数据。

## 10. 开发适配边界

| 边界项 | 要求 |

| 技术自由度 | 本文不规定组件名称、状态变量、接口路径与方法、请求响应结构、错误码、缓存策略或代码组织方式 |
| 数据来源 | 原型中的示例数据仅用于展示；正式环境接入项目已确定的数据来源 |
| 缺口处理 | 现有工程缺少必要能力时，先输出技术设计或待确认问题，不得把假设写成已确认产品规则 |
