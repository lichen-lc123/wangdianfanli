# 文档模板执行索引

生成或修改 PRD 前，先阅读 [PRD 编写边界](../../01-全局背景信息/PRD编写边界.md)。产品 PRD 负责业务、交互和验收口径，具体技术选型进入独立技术设计。

| 交付物 | 使用位置 | 说明 |
|---|---|---|
| 业务 PRD | `业务prd/主PRD模板.md` | 定义背景、范围、流程、状态、规则、异常和验收标准 |
| 交互 PRD | `前端Demo PRD/标准型页面&模块的PRD文档集/前端Demo_列表页模板.md` | 定义页面结构、控件能力、可见状态、交互和页面验收标准 |
| 字段清单 | `前端Demo PRD/` 下对应字段清单模板 | 作为字段名称、类型、来源、枚举和字段约束的唯一真相源 |

执行顺序：字段清单确认 → 业务 PRD → 交互 PRD → 技术设计 → 开发实现。
