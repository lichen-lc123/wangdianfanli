# 强盛进销存 UI 规范库

> **当前项目最高优先级 UI 规范：** [RH_design_token_v3.0.md](./RH_design_token_v3.0.md)。颜色、字体、间距、圆角、阴影、组件状态、页面布局或交互规则与其他 UI 文档不一致时，以该文档为准；业务字段与业务逻辑不受 UI 规范覆盖。

## 一、文档定位

这套规范库不是通用设计理论手册，而是当前项目可执行的页面与组件约束库。

它同时服务 3 类对象：

- **实现者**：快速找到唯一规范来源，不再凭感觉搭页面
- **AI**：读取稳定输入边界，减少风格漂移和结构跑偏
- **项目文档**：把页面骨架、控件规则、状态规则从业务文档里剥离出来，形成独立约束层

具体怎么用、冲突时以谁为准，见 [00-规范使用说明.md](./00-规范使用说明.md)。
