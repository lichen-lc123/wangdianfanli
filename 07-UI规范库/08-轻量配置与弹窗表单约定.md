# 轻量配置与弹窗表单约定

> **版本**：V1.0  
> **日期**：2026-08-12  
> **依据**：数据字典重构走查（两级类别 + 资料项弹窗维护）  
> **目的**：把“什么时候用独立页、什么时候用弹窗、弹窗长什么样”写成可复用约定，避免后续同类模块再次做成过重的标准主数据详情页。

## 一、先判定模块形态

新增基础资料 / 配置类模块前，先选形态，再写 PRD 和画骨架：

| 形态 | 适用条件 | 页面结构 | 样例 |
| :--- | :--- | :--- | :--- |
| **标准主数据** | 字段分组多、业务属性重、需要完整详情与操作日志 | 列表 + **独立**新增/编辑/详情页 | 商品、客户、供应商、仓库、物流 |
| **轻量配置 / 字典类** | 字段少（通常 ≤8 个业务字段）、以取值维护为主、可左右分栏或单列表 | **工作台** + **弹窗**查看/新增/编辑；不做独立详情页 | 数据字典（分组/叶子/资料项） |

判定口诀：

1. 打开详情是不是几乎只有编码、名称、状态、备注？→ 倾向弹窗。  
2. 是否需要操作日志、流转记录、复制新增、多分组详情？→ 倾向独立页。  
3. 是否存在「类别树 / 配置树 + 叶子下的取值列表」？→ 轻量配置，叶子下的对象用弹窗。

**禁止**：轻量配置照搬标准主数据的「独立详情页 + 操作日志卡片」。

## 二、轻量配置的信息架构

### 2.1 可选的左右分栏

```text
左侧：类别 / 分组树（可维护）
右侧：当前叶子下的资料项列表（查询 + 表格 + 分页）
```

一期树深度默认 **两级**：一级分组 + 二级叶子。多级树未确认前不做。

| 节点 | 能否挂资料项 | 说明 |
| :--- | :---: | :--- |
| 分组（一级） | 否 | 只用于组织；选中时右侧提示「请选择叶子」 |
| 叶子（二级） | 是 | 业务按叶子类别编码取数 |

### 2.2 容器清单写法（给页面骨架）

轻量配置在骨架「页面与容器清单」中应写成：

| 容器 | 用途 |
| :--- | :--- |
| 工作台（列表） | 查询与行操作入口 |
| 查看弹窗 | 只读展示 |
| 新增/编辑弹窗 | 表单维护 |
| 类别维护弹窗 | 如有树，维护分组/叶子 |
| 启禁用/删除确认弹窗 | 风险动作 |

**不要**默认列出「详情页 / 新增页 / 编辑页」，除非本模块明确选了标准主数据形态。

## 三、弹窗表单（Modal）组件结构

对齐项目已有弹层（如选商品弹窗、Drawer）：

```text
+------------------------------------------+
| 标题                                 [x] |
|------------------------------------------|  ← border-b
| 内容区（字段只读或表单）                   |
|------------------------------------------|  ← border-t
|                        [次按钮] [主按钮]  |
+------------------------------------------+
```

### 3.1 必须遵守

| 约定项 | 规格 |
| :--- | :--- |
| 标题区 | 左侧标题，右侧关闭 `×`（`aria-label="关闭"`） |
| 标题分割线 | 标题区底部 `border-b border-line-1` |
| 底部操作区 | 右对齐；与内容区用 `border-t border-line-1` 分隔 |
| 宽度 | 轻量约 `480–560px`；中量复杂表单约 `720px` |
| 高度 | 内容过长时中部滚动，标题与底部按钮固定 |
| 关闭方式 | `×`、底部「关闭/取消」、点击遮罩（确认类弹窗可不点遮罩关闭） |

### 3.2 明确禁止

- 把 **使用状态** 做成标题栏右侧徽章/Pill（易与关闭按钮抢视觉，且不像字段）  
- 标题区堆操作按钮（启用/禁用/删除应留在列表行或独立确认弹窗）  
- 弹窗内再嵌完整页面壳（面包屑、大页头、操作日志）  
- 查看弹窗默认展开操作日志

### 3.3 查看弹窗字段

- 状态、引用情况等一律作为**内容区普通字段**展示（状态可用 `StatusPill`，但仍挂在「使用状态」标签下）  
- 创建人 / 创建时间：查看弹窗可展示；新增/编辑弹窗不展示  
- 最后修改人 / 最后修改时间：轻量配置默认不展示，除非 PRD 明确要求

### 3.4 底部按钮

| 模式 | 次按钮 | 主按钮 |
| :--- | :--- | :--- |
| 查看 | 关闭 | 编辑（切入编辑弹窗，不跳页） |
| 新增/编辑 | 取消 | 保存 |

## 四、交互与能力边界

| 能力 | 轻量配置默认 | 标准主数据默认 |
| :--- | :--- | :--- |
| 查看 | 弹窗 | 独立详情页 |
| 新增/编辑 | 弹窗 | 独立表单页 |
| 启用/禁用 | 列表行 + 确认弹窗 | 列表行/详情页 + 确认弹窗 |
| 删除 | 按业务 PRD；常允许删未引用记录 | 默认不提供，以禁用代替（仓库等例外以 PRD 为准） |
| 操作日志 | **不做** | 详情页可折叠日志 |
| 复制新增 | 默认不做 | 详情页可提供 |
| 路由 | 通常只注册工作台列表路由 | 注册 list / new / :id / :id/edit |

编码被引用后只读、新建默认启用、启禁用不进表单等规则，与标准主数据一致。

## 五、文档层怎么写（PRD / 骨架 / 字段清单）

### 5.1 主 PRD / 简单型 PRD

在「页面目标与范围」增加一行：

| 维护形态 | 轻量配置（工作台 + 弹窗） / 标准主数据（独立页） |

并在「明确不做」写清：独立详情页、操作日志（若选轻量）。

### 5.2 页面骨架

- 容器清单按第二节表格列弹窗，不列假详情页  
- ASCII 线框给弹窗单独画一节，画出标题 `[x]`、上下分割线、底栏按钮  
- 左右分栏模块须写清：选中分组时的右侧空态文案

### 5.3 前端 Demo PRD

- 功能落点写「→ 弹窗」，不写「→ 详情页」  
- 验收增加：弹窗有关闭图标与标题分割线；状态在内容区；无操作日志

### 5.4 字段清单

- 「详情展示」列可理解为「查看弹窗展示」；备注写明 `轻量配置：查看=弹窗`  
- 「新增页 / 编辑页」列可写「弹窗可编辑」  
- 不要仅为轻量配置强行增加操作日志相关字段投影

## 六、前端落点（原型工程）

| 事项 | 约定 |
| :--- | :--- |
| 路由 | `workspaceOnly`：只挂工作台 path；不注册 `/new`、`/:id`、`/:id/edit` |
| 列表编码链接 | 打开查看弹窗，不 `navigate` 到详情 |
| 契约 | 仍可用 `CrudModuleDefinition` 管列表列与校验；UI 由工作台页自绘弹窗 |
| 样例实现 | `src/pages/DataDictionaryPages.tsx` |

## 七、验收核对清单

- [ ] 形态判定写进 PRD，未误用标准主数据详情模板  
- [ ] 查看/新增/编辑为弹窗；无操作日志  
- [ ] 弹窗：标题 + `×` + 标题下划线 + 底栏上划线  
- [ ] 使用状态在内容区，不在标题栏右上角  
- [ ] 若有类别树：仅两级；仅叶子可维护资料项  
- [ ] 骨架容器清单与真实交互一致（不画未实现的独立页）
