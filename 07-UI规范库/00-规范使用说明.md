# 规范使用说明

## 一、适用范围

适用于：

- `99-产品原型prototype` 目录下的 React + Tailwind CSS + TypeScript 原型
- 强盛进销存项目已规划的工作台、列表页、详情页、表单页、弹层表单
- 轻量配置 / 字典类工作台与弹窗维护（见 `08-轻量配置与弹窗表单约定`）
- 后续新增的同一后台体系页面

不直接覆盖：营销首页、图表大屏、独立新产品线。

## 二、使用方式

**页面实现前**：先看项目原型的页面清单与功能范围，再查 `02-页面模板与实例映射` 和对应模板/组件规范。

**页面走查时**：检查模板是否正确、组件组合是否正确、状态/权限/异常态是否补齐、是否违反系统级尺寸和密度规则。

**给 AI 产出时**：必须同时提供页面业务目标、模板类型、规范章节、输出格式要求。禁止只给一句“帮我画一个列表页”。

## 三、优先级判定

冲突时优先级从高到低：

1. 当前项目已确认的 Figma 节点
2. 本规范库明确写死的项目规则
3. Arco 式后台默认规则
4. 实现者或 AI 的主观发挥

规范未覆盖时，采用 Arco 默认规则，并在实现说明里标记：`默认推理规则，待 Figma 或规范补充确认`。

规范与早期原型代码冲突时，以规范为准，代码需校正。

## 四、维护原则

- 规则写在模板、组件、状态层，不在每个页面文档里重复
- 一条规则只有一个主入口
- `02-页面模板与实例映射` 只回答“这个页面要读哪些规则”，不重复规则正文
