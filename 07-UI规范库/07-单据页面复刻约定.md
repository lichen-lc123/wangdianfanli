# 单据页面复刻约定

## 一、目的与范围

本文件沉淀**业务单据**（采购订单、销售订单、入库单、出库单等）在列表、新增/编辑、详情三类页面上已跑通的 UI 与组件约定，供 Demo PRD 编写与前端原型复刻时直接引用。

适用范围：

- 有状态流转、有商品/明细行的业务单据
- 不适用于主数据管理页（商品、客户、供应商、仓库等，见 `06-模块契约与原型复刻规范.md` §四）

冲突时优先级：`字段清单 > 主 PRD > Demo PRD > 本文件 > 代码现状`

## 三、页面级 UI 约定（Demo PRD 必须写明）

### 3.1 列表页

| 约定项 | 规格 |
| --- | --- |
| 单据号列 | 左固定；**不提供表头排序**（无排序图标） |
| 操作列 | 右固定；行内文字操作**左对齐**（`DocumentRowActions` + `documentListActionColumn`）；冻结边界使用左侧分割线与柔和阴影，按钮组间距统一为 `4px` |
| 可排序列 | 由 Demo PRD 逐列声明；未声明的列不得出现排序图标 |
| 行内操作 | 按状态动态展示；**禁止渲染 disabled 操作** |
| 列表状态恢复 | 配置化列表须在 config 传 `sessionKey`（或收付款 `listSessionKey`），从详情/编辑返回时恢复筛选、Tab、分页；命名建议 `{模块}-list-state` |

### 3.2 新增/编辑页

| 约定项 | 规格 |
| --- | --- |
| 返回列表 | 使用 `BackToListButton`（幽灵按钮 + 左箭头），置于页头操作区最左侧 |
| 页头布局 | 标题 + 右上角操作组（返回 / 保存 / 保存并提交）；**不使用固定底部操作栏** |
| 页头状态 | **新增/编辑模式均不展示**状态 Tag |
| 账期天数等数字输入 | 左对齐，不使用 `text-right` |
| 价税列命名 | 统一为：`含税单价` / `不含税单价` / `含税金额` / `不含税金额` / `税额`（不用「单价（含税）」等括号式命名） |
| 价税列对齐 | 表头与数值列均**右对齐** |
| 行内金额 | 普通字重，不对单个金额列单独加粗 |
| 明细合计行 | 合计值**与表头列对齐**分别展示，不用 `colSpan` 合并成单行右对齐文案 |
| 合计行样式 | `font-semibold text-text-2`（不用 `text-text-1`，不用 `bg-zinc-100`） |
| 商品选择弹窗 | 引用 `PurchaseProductPickerModal` 或同类组件；写明弹窗宽度与列宽约束 |

### 3.3 详情页

| 约定项 | 规格 |
| --- | --- |
| 返回列表 | 同新增/编辑页，使用 `BackToListButton` |
| 状态展示位置 | 放在**基本信息卡片**内，紧跟单据号；**页头标题区不展示状态 Tag** |
| 明细表 `colgroup` | 列数必须与表头/表体/合计行一致，避免金额列视觉错位 |
| 明细合计行 | 同新增/编辑页，按列对齐展示数量与三项金额 |
| 按状态显隐列 | 在 Demo PRD 逐列声明（如累计入库数量、未入库数量） |

## 四、Demo PRD 编写检查项

编写或评审单据 Demo PRD 时，以下条目必须在对应章节出现（可复制到验收清单）：

**列表页**

- [ ] 单据号列：左固定、不可排序
- [ ] 操作列：右固定、行内操作左对齐（`DocumentRowActions`）
- [ ] 状态 Tab：`DocumentListFilterSection` + underline 样式
- [ ] 可排序列清单（若有）
- [ ] 行内操作按状态矩阵，不写 disabled 态
- [ ] 列表 `sessionKey`：Demo PRD 或 listConfig 中声明，与 `useDocumentListQuery` 一致

**新增/编辑页**

- [ ] 返回列表：`BackToListButton` 规格
- [ ] 页头不展示状态 Tag（新增/编辑均不展示）
- [ ] 价税五列命名与右对齐
- [ ] 明细合计行：列对齐方式与样式
- [ ] 商品选择弹窗：组件名 + 列宽/布局约束

**详情页**

- [ ] 状态在基本信息卡片，不在页头
- [ ] 返回列表按钮规格
- [ ] 明细按状态显隐列规则
- [ ] 合计行列对齐规则
