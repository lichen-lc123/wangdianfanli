# 系统级约束与 Token 基线

## 一、设计方向

当前项目采用 Arco 式紧凑后台，不是展示型卡片后台。

核心标准：

- 信息密度高于装饰表达
- 规则感强于情绪化视觉
- 结构连续感强于大面积浮层卡片感
- 页面优先服务“查、录、审、看、流转”

应该：小圆角、浅阴影、白底+暖灰底分层、橙色为唯一品牌主强调色、局部用暖金/琥珀/暖红表达成功、警告和错误状态。

不应该：大圆角、厚重投影、过强渐变背景、大面积营销风文案、到处都是卡片壳。

## 二、系统级固定约束

**框架尺寸**

- 顶栏高度：`54px`
- 侧栏宽度：`200px`
- 主控件高度：`32px`
- 次级小按钮高度：`28px`
- 菜单项高度：`42px`
- 表格常规表头/行高：`38-46px`

**页面结构**

```text
顶栏
侧栏
内容容器
  页面头部
  页面主内容
系统级浮层（个人信息下拉、全局筛选弹层、抽屉、确认弹窗）
```

**响应式**

- 桌面端保留完整后台框架
- 窄屏侧栏改抽屉，不压成超窄菜单
- 表格、子表格允许横向滚动，不强行压列
- 表单采用降列策略，控件不过度缩窄

## 三、全局组件规则

**顶栏**：系统 logo 与名称、全局搜索、系统级 icon 入口、用户头像入口。

**个人信息下拉**：不是普通菜单，必须包含头像与用户名、辅助身份信息、主操作/升级入口、分组菜单、至少一个状态块或开关项。

**页面主容器**：连续工作面，允许区块分层，但不应把每个区块都包成风格过强的独立大卡片。

## 四、颜色基线

亮色模式采用橙色品牌主题，主色阶与基础色如下：

- `Brand/1 = #FFF7ED`（浅橙背景、选中态浅底）
- `Brand/2 = #FFEDD5`（浅橙悬浮背景）
- `Brand/3 = #FED7AA`（浅橙边框）
- `Brand/4 = #FDBA74`（弱强调）
- `Brand/5 = #F97316`（悬浮态）
- `Brand/6 = #EA580C`（主按钮、链接、选中态）
- `Brand/7 = #C2410C`（按下态、深色强调）
- `Text/5 = #292524`
- `Text/4 = #57534E`
- `Text/3 = #A8A29E`
- `Fill/1 = #FFFFFF`
- `Fill/2 = #FAFAF9`
- `Fill/3 = #F5F5F4`
- `Fill/4 = #E7E5E4`
- `Line/2 = #E7E5E4`
- `Line/3 = #D6D3D1`
- `Danger/6 = #DC2626`（暖红）
- `Warning/6 = #D97706`（琥珀）
- `Success/6 = #A16207`（暖金）

代码 token 命名建议：`brand-*`、`text-*`、`fill-*`、`line-*`、`success`、`warning`、`danger`；语义色在 CSS 中使用 `--success-6`、`--warning-6`、`--danger-6` 及对应 `*-light` 背景变量，Tailwind 只映射变量，不直接写 HEX。

主题通过 `:root[data-theme="light|dark"]` 切换；页面背景、文字、填充、边框、状态色、遮罩和阴影均从语义变量取值，组件不得自行维护第二套主题色。

禁止直接在页面里写随机 HEX 值，除非是插图或临时占位。

## 五、尺寸与代码基线

**高层原则**

- 字号：正文 14px，标题逐级放大，辅助说明 12-13px
- 间距：基于 4px 网格，常用 4 / 8 / 12 / 16 / 20 / 24px
- 圆角：小圆角为主，后台主容器不使用 16px+ 大圆角
- 阴影：轻阴影或极浅阴影，禁止厚重投影

具体 Token 映射、Tailwind 类名、组件 API 参考 `99-产品原型prototype/src/docs/UI-DESIGN-GUIDE.md`。

**响应式断点**

- `sm >= 640`
- `md >= 768`
- `lg >= 1024`
- `xl >= 1280`

`lg` 以上视为完整后台；`lg` 以下切抽屉侧栏；表格和宽子表格允许横向滚动。

**技术栈**：React + TypeScript + Tailwind CSS，以语义组件封装基础控件。

**代码组织原则**

- 颜色和尺寸通过 token 表达，不在页面散写
- 布局优先由模板组件决定，不在页面里随意自由布局
- 表格、表单、浮层等高频能力优先沉淀成通用结构
- 可排序表头、选择器和顶部图标入口必须使用可聚焦语义元素，并提供对应的 ARIA 状态或标签。

## 六、颜色占位符避坑

由于 Tailwind CSS 的 `/{opacity}` 修饰符在遇到未规范解析的 CSS Variables 色值时会导致静默渲染失效，**绝不允许**使用 `bg-brand-6/10`、`bg-success/5`、`text-danger/80` 等透明度修饰符。必须显式声明语义对应阶梯的基础色，例如 `bg-brand-1 text-brand-6` 或 `bg-success-light text-success`。

## 七、默认推理规则

Figma 未明确节点时默认采用：

- 个人信息下拉宽度：`220-260px`
- 抽屉宽度：`520px` 或 `720px`
- 弹窗标题区高度：`56-64px`
- 弹层底部操作区高度：`56px`
