## 1. 设计原则

| 编号 | 原则 | 说明 |
|:---:|------|------|
| 1 | **一致性** | 同一功能在不同页面保持相同交互方式和视觉风格，减少用户学习成本。 |
| 2 | **高效** | 简化操作流程，支持批量操作，常用功能前置，让用户更快完成任务。 |
| 3 | **及时反馈** | 操作后立即给出状态反馈——按钮 loading、toast 提示、表单校验等。 |
| 4 | **防止出错** | 危险操作前二次确认，误操作后可撤销，用限制条件预防错误发生。 |
| 5 | **可预测** | 用户能预判操作结果，界面行为符合心智模型，降低认知负担。 |
| 6 | **渐进披露** | 复杂功能分层展示，基础操作前置，高级功能按需展开。 |

## 原型实施约定（AI 出原型默认规则）

> AI 生成原型时的默认约定。本节为快速参照，与后续组件规格冲突时以本节为准。

**用色纪律**

| 层级 | 色值 | 用途 | 约束 |
|------|------|------|------|
| 主品牌橙 | `#FA541C` | 主操作按钮、选中态、聚焦边框 | 只给"一个主操作 + 选中/聚焦态"，不全页铺开 |
| 次要橙 | `#E86520` | 表格操作链接等高频次要操作 | 醒目但不刺眼，与主按钮分主次；悬停加深 `#C94D00` |
| 品牌浅橙 | `#FFF0E8` | 数据行悬停、选中行底色 | 让悬停/选中带品牌感，不用冷灰 |
| 正文深色 | `#1B1F26` | 表格主体内容、正文 | 密集表格用重要色，扎实易读 |

原则：橙色无处不在会让页面发躁。主按钮主橙、行内操作次要橙、正文深色无橙，构成三档层级。

**数据表格约定**

| 维度 | 约定 |
|------|------|
| 密度 | 紧凑档：正文 13px、表头 12px/600、行高 40px（非默认 14px/48px，数据密集表小字号矮行高扫读效率更高） |
| 字体 | 正文统一一个字号、一个深色（#1B1F26）、常规字重；不加粗（整列加粗=没加粗，反增视觉重量） |
| 辅助 | 单位/辅助信息 12px 浅灰 `#93969C`；列标题已含语义时，单元格内单位（如"个实体"）冗余应删 |
| 对齐 | 文字列左对齐；纯数字列（金额/占比）右对齐；带单位或语义的计数（如"关联组织"=8）左对齐更干净；操作列右对齐；列标题与内容同向 |
| 悬停 | 行悬停用极浅橙 `#fffaf5` |
| 操作列 | 次要橙 `#E86520`、13px，悬停加深 `#C94D00` |

**查询工具栏约定**

| 维度 | 约定 |
|------|------|
| 字号 | 搜索框、筛选下拉、查询/重置按钮统一 12px 紧凑档（与表格辅助信息一致），工具栏是次要操作区，不用 14px |
| 标签 | "组织类型：""状态："等筛选标签 12px 浅灰，比控件再小一档 |

**表单与交互约定**

- 只读/不可编辑字段必须置灰：灰底 `#F5F5F7` + 灰字 `#B5B9BF` + not-allowed 光标。只加 readonly 不置灰，等于没传达"别碰"。
- 系统生成字段（如编码）弱化：新增时不展示，编辑时置灰只读展示，放首行作"改的是哪条"记录标识。
- 二值状态（启用/停用）用 Switch 开关，不用下拉。
- 回车跳下一焦点；textarea 用 Shift+Enter 换行；打开弹窗默认聚焦首个必填输入。
- 回车跳转监听必须加 `!e.isComposing` 守卫，否则中文输入法敲回车确认候选词时会误触发跳转、文字窜入下一字段。
- 状态变更单一入口：停用（有影响）走二次确认弹窗并讲清后果，关联拦截优先于确认；启用（安全/恢复）直接执行，不加确认打扰。

**元素取舍原则**

- 每个设计元素须证明存在价值，否则删除或简化（如冗余的状态圆点、整列加粗、单元格内重复单位）。
- 同一操作只保留一个入口，删除冗余入口，避免用户困惑"到底哪能改"。

## 2. 基础设计规范

### 2.1 色彩规范

#### 2.1.1 品牌色 — 主要

> 用于核心操作和品牌强调

| 状态 | 色值 | 用途 |
|------|------|------|
| 点击态 | `#D84315` | 按钮点击按下态、链接 active 态、Tab 切换按下瞬间、单选/多选按下态 |
| 默认态 | `#FA541C` | 主按钮背景、文字链接、进度条、Loading 旋转、复选框/单选框选中态、开关开启态 |
| 禁用态 | `#F5C4A8` | 主按钮禁用态、表单提交中不可点击的按钮、已跳转完毕的链接 |
| 浅色底 | `#FFF0E8` | 表格选中行底色、成功提示背景、浅色标签底色、Tooltip 文字 |

#### 2.1.2 品牌色 — 次要

> 少用，用于标签、图标装饰。默认态 #E86520 与功能警告色同值，是系统的"次要橙"，兼用于装饰/次要操作（如表格操作链接）与警告反馈。

| 状态 | 色值 | 用途 |
|------|------|------|
| 点击态 | `#C94D00` | 次要装饰按钮按下态、图标按钮按下反馈 |
| 默认态 | `#E86520` | 装饰性小图标、分类标签 Tag 文字、徽章 Badge 数字角标背景 |
| 禁用态 | `#FFD4B8` | 次要装饰按钮禁用态、不可操作的图标按钮 |
| 浅色底 | `#FFF4EC` | 浅色标签 Tag 背景、次要信息区域底色、图表辅助色块 |

#### 2.1.3 功能色

> 用于状态反馈

| 类型 | 色值 | 用途 |

| 警告 | `#E86520` | 警告 Warning 提示、数据异常警告、即将过期提醒（与品牌次要橙同值，见 2.1.2） |

| 成功-禁用 | `#8AE59B` | 已完成但不可操作的状态、不可重复提交的成功结果 |
| 错误-禁用 | `#F5A8A0` | 已处理的异常状态、不可重试的失败结果 |
| 成功-浅色 | `#EBFFEE` | 成功提示的浅色底色、操作成功的行高亮 |

## 3. 页面布局系统

### 3.1 整体布局结构

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 侧边栏    │                        顶栏                                      │
│ (菜单栏)  │   [面包屑]                    [消息] [头像] [设置]              │
│           ├──────────────────────────────────────────────────────────────────┤
│           │   标签栏   [标签1] [标签2] [标签3]                               │
│           ├──────────────────────────────────────────────────────────────────┤
│           │                                                                  │
│           │                        内容区                                    │
│           │                                                                  │
│           │                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 3.1.1 响应式断点规则

| 屏幕宽度 | 菜单栏 | 内容区内边距 | 卡片间距 | 说明 |
|----------|--------|-------------|----------|------|
| **≤1200px** | 自动收起 64px | 16px | 12px | 小屏设备，菜单默认收起 |
| **1201~1440px** | 210px / 64px | 20px | 16px | 笔记本、小显示器，最常用 |
| **1441~1920px** | 210px / 64px | 24px | 20px | 标准桌面显示器 |
| **≥1921px** | 210px / 64px | 32px | 24px | 大屏/超宽屏 |

#### 3.1.2 布局容器尺寸

| 容器区域 | 属性 | 规格值 | 说明 |
|----------|------|--------|------|
| **左侧菜单栏** | 展开宽度 | 210px | 系统导航菜单，固定宽度 |
| | 收起宽度 | 64px | 所有屏幕尺寸统一收起宽度 |
| | 高度 | 100%（直达顶部） | 从页面顶部到底部，包含 Logo 区域 |
| | 背景色 | #FFFFFF | 白色背景，右侧 1px 分割线 #F0F0F2 |
| **顶栏** | 高度 | 48px | 位于菜单栏右侧，与内容区等宽 |
| | 宽度 | calc(100% - 菜单栏宽度) | 不是横跨整个页面，仅在内容区顶部 |
| | 背景色 | #ffffff | 白色背景，底部 1px 分割线 #E8E8ED |
| **标签栏** | 高度 | 34px | 顶栏下方，显示已打开的菜单页面标签 |
| | 宽度 | 100%（减去菜单栏） | 与内容区同宽 |
| | 背景色 | #FFFFFF | 白色背景，底部 1px 分割线 #E8E8ED |
| **内容区** | 宽度计算 | calc(100% - 菜单栏) | 自适应剩余空间 |
| | 高度 | calc(100vh - 48px - 34px) | 占满视口高度减去顶栏和标签栏高度 |
| | 背景色 | #F5F5F7 | 浅灰色背景，区分内容层次 |
| | 内边距 | 20px ~ 32px | 随屏幕宽度响应式变化 |
| | 溢出处理 | overflow-y: auto | 内容超出时独立滚动 |

#### 3.1.3 布局容器宽度计算公式

| 屏幕宽度 | 菜单栏 | 内容区宽度 | 内容区内边距 |
|----------|--------|-----------|-------------|
| **≤1200px** | 64px | calc(100% - 64px) | 16px |
| **1201~1440px** | 210px | calc(100% - 210px) | 20px |
| **1441~1920px** | 210px | calc(100% - 210px) | 24px |
| **≥1921px** | 210px | calc(100% - 210px) | 32px |
